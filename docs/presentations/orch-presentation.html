La solución

Cómo funciona

Tres pasos. No más.

01
Definís las tareas

Describís lo que cada agente tiene que hacer en un JSON simple.

{
 "id": "landing",
 "description": "Build landing",
 "depends_on": []
}
02
orch despacha

Camina el grafo de dependencias y corre cada tarea en el agente correcto.

$ orch dispatch
→ landing queued
→ api queued
→ auth blocked
03
Tu cliente ve el dashboard

Compartís una URL. El cliente ve ETA y estado de cada tarea en tiempo real.

🔒 orch.local/dashboard
# compartí este link
# no se necesita cuenta
